# Travel Photos Directory

This directory contains travel photos organized by country:

## Structure

- `malaysia/` - Photos from Malaysia
- `singapore/` - Photos from Singapore
- `vietnam/` - Photos from Vietnam
- `australia/` - Photos from Australia
- `sri-lanka/` - Photos from Sri Lanka
- `new-zealand/` - Photos from New Zealand

## Adding Photos

1. Place photos in the appropriate country folder
2. Use descriptive filenames (e.g., `kuala-lumpur-skyline.jpg`)
3. Recommended formats: JPG, PNG, WebP
4. Recommended max size: 1920x1080 for web optimization

## Usage

Photos are displayed in the Interactive World Map component when users click on country pins.
