# Gayan's Portfolio

A minimal, single-page portfolio website built with Next.js 15, React 19, TypeScript, and Tailwind CSS. Features smooth scroll navigation, elegant animations, and a custom navy + beige theme.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## 🎨 Design Features

- **Single-page design** with smooth scroll navigation
- **Minimal & clean** layout inspired by modern portfolios
- **Custom navy + beige theme** with luminous green code highlights
- **Smooth animations** and hover effects
- **Responsive design** that works on all devices
- **Fixed navigation** with active section highlighting
- **Side navigation indicators** (desktop)
- **Scroll-to-top button**

## 🛠️ Tech Stack

- **Framework:** Next.js 15
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Fonts:** Montserrat & JetBrains Mono
- **Deployment:** Vercel

## 📦 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## 📁 Project Structure

```
src/
  app/
    globals.css      # Custom styles and animations
    layout.tsx       # Root layout with fonts
    page.tsx         # Single-page portfolio
public/
  documents/
    cv.pdf          # Resume/CV download
```
